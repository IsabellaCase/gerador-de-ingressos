# Gerador de ingressos — Coding Conf

Formulário responsivo e acessível para gerar um ingresso personalizado para a Coding Conf.

## Como executar

Abra `index.html` em um navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Recursos

- Validação de campos obrigatórios, e-mail e avatar PNG/JPG de até 500KB.
- Seleção de imagem pelo teclado ou arrastar e soltar, com prévia do avatar.
- Ingresso personalizado exibido após o envio válido.
- Layout responsivo, estados de foco e mensagens acessíveis a leitores de tela.
